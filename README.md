# Claude Code for Creatives

A workshop presentation for artists, designers, and makers — turning "I Wish I Could" into "Let Me Just Ask."

Built with [Slidev](https://sli.dev/).

## View Online

**[sultanpeyek.github.io/dagodao-claude-code-for-creatives](https://sultanpeyek.github.io/dagodao-claude-code-for-creatives)**

## Local Development

```bash
bun install
bun dev
```

Then visit http://localhost:3030
